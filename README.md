## 🚀 Featured projects

### 🔎 [The Research Room](https://github.com/Pannu99yogesh/Research_room) · [Live demo](https://research-room.streamlit.app/)
A multi-agent research assistant that turns a question into a cited report.

<img src="assets/pipeline.svg" width="100%" alt="Question, then Planner, Researcher and Writer agents, then a cited report">

- **Planner → Researcher → Writer** workflow orchestrated with LangGraph
- Web evidence from Tavily, Groq as the primary model with Gemini fallback
- Saved report history and PDF / Markdown export

`Python` `LangGraph` `LangChain` `Groq` `Gemini` `Tavily` `Streamlit`

### 🩺 [DataDoctor](https://github.com/Pannu99yogesh/DataDoctor) · [Live demo](https://datakadoctor.streamlit.app)
A data quality analyzer for CSV and Excel files.
- Finds missing values, duplicate rows and IQR outliers
- Cleans data and compares a quality score before and after
- Exports the cleaned CSV and a PDF report

`Python` `Pandas` `NumPy` `Plotly` `ReportLab` `Streamlit`

### 📄 [PDF Query Engine](https://github.com/Pannu99yogesh/pdf-query-engine) · [Live demo](https://pdf-query-engine-xcj5wx9zcxxub9pezamgcc.streamlit.app/)
Ask questions about a PDF and get answers grounded in its text (RAG).
- Chunks the document and retrieves relevant passages with FAISS
- MiniLM sentence embeddings, answers generated through Groq
- Prompted to say when the answer isn't in the document

`Python` `LangChain` `FAISS` `Hugging Face` `Groq` `Streamlit`

### 🤖 [Ultron AI](https://github.com/Pannu99yogesh/Ultron-Ai)
A voice-driven desktop assistant.
- Classifies spoken commands into chat, web search, automation or image generation
- Speech-to-text, text-to-speech and a PyQt5 interface

`Python` `PyQt5` `Cohere` `Groq` `Stable Diffusion` `Selenium`
